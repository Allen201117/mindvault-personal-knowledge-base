# MindVault · 个人知识库

一个面向个人知识管理场景的轻量级 Web 应用，帮助用户完成知识的收集、整理、检索与回顾闭环。

## 在线体验

- 部署链接：https://knowledge-base-lilac.vercel.app
- GitHub 仓库：https://github.com/Allen201117/mindvault-personal-knowledge-base

## 项目定位

随着信息获取越来越碎片化，很多内容会停留在收藏夹、备忘录、截图和浏览器标签页里，最终形成“收藏即遗忘”。

MindVault 的目标不是做一个通用笔记软件，而是做一个聚焦“个人知识资产管理”的轻量工具，让用户能够：

- 快速记录一条知识卡片
- 用分类与标签整理知识
- 通过搜索和筛选快速定位
- 通过回顾机制反复提取和巩固知识

## 核心功能

- Dashboard 首页：查看知识总量、收藏数、待回顾数量、最近添加、分类分布与热门标签
- 新增知识：录入标题、内容、分类、标签、来源链接与个人笔记
- 知识列表：支持搜索、分类筛选、标签筛选、收藏筛选与排序
- 知识详情：查看完整内容、来源、笔记，支持收藏与删除
- 回顾模式：以闪卡形式回顾知识，支持待回顾/收藏精选/全部随机三种模式
- 本地持久化：所有数据保存到浏览器 localStorage，零后端依赖
- 示例数据：预置多条知识卡片，首次打开即可完整体验产品能力

## 页面结构

- `/`：Dashboard / 首页
- `/knowledge`：知识列表页
- `/knowledge/new`：新增知识页
- `/knowledge/[id]`：知识详情页
- `/review`：知识回顾页

## 技术方案

- Next.js 16
- React 19
- Tailwind CSS 4
- Lucide React
- localStorage 持久化

## 面试简述

MindVault 是一个轻量级个人知识库产品，核心不是记笔记，而是帮助用户真正管理知识资产。我围绕“收集、整理、检索、回顾”四个环节设计了完整的产品闭环：用户可以快速录入知识卡片，通过分类和标签管理，通过搜索和筛选快速定位，并通过闪卡式回顾机制反复提取知识、避免收藏即遗忘。项目使用 Next.js + Tailwind CSS 构建，采用 localStorage 持久化，避免复杂后端依赖，确保 MVP 完整、稳定、可部署，适合作为面试笔试作品展示。
